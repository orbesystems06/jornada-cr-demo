# Jornada CR — demo interactivo

Este sitio es una demostración pública de la interfaz de ventas. No es el servicio real y no debe usarse para vender, cobrar, pagar premios ni guardar datos comerciales.

- No tiene servidor, autenticación ni cuentas.
- Las ventas y los saldos simulados se guardan solo en el almacenamiento local del navegador actual; no se comparten entre personas ni dispositivos.
- Los datos del demo se pueden borrar desde el aviso superior.
- El código HTML, CSS y JavaScript servido por GitHub Pages es público y puede inspeccionarse.
- Los sorteos y resultados mostrados no son una fuente oficial.

La aplicación real necesita un servidor protegido y una base de datos persistente. El backend no forma parte de este sitio.
